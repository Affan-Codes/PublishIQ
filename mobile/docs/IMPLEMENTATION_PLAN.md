# PublishIQ Mobile Implementation Plan

This implementation plan maps each web route to its corresponding mobile screen(s), the backend API endpoints consumed, and the handled states (loading skeletons, empty states, error states, and mutation feedback).

---

## Route & Endpoint Mapping

| Web Route | Mobile Screen(s) | Backend Endpoints | Handled States |
|---|---|---|---|
| `/login` | `src/app/(auth)/login.tsx` | `POST /auth/login`, `GET /auth/session` | Loading: `isSubmitting` button spinner & disabled inputs. Error: inline Zod errors, 401 message banner, 429 rate limit warning, network retry banner. Success: toast + navigation to dashboard. |
| `/` (Dashboard) | `src/app/(app)/(tabs)/index.tsx` | `GET /dashboard/stats`, `POST /jobs/:id/retry` | Loading: `SkeletonStatCard` (KPIs), `SkeletonCard` (Failures, Queue, Connections, Publications). Empty: empty cards for zero failures / publications. Error: `ErrorState` with "Try Again" & "Refresh Data". Mutation feedback: retry button loading state + success/error toast. Pull-to-refresh & 15s focus-gated polling. |
| `/jobs` (Jobs Tab) | `src/app/(app)/(tabs)/jobs.tsx` (Segmented: Jobs) | `GET /jobs` (paginated `useInfiniteQuery`), `POST /jobs` (Create Job) | Loading: `SkeletonCard` list. Empty: `EmptyState` "No jobs found". Error: `ErrorState`. Mutation feedback: create job modal with loading state and success toast. Pull-to-refresh & 10s conditional polling (active if any job is non-terminal). |
| `/jobs` (Generated Content Tab) | `src/app/(app)/(tabs)/jobs.tsx` (Segmented: Generated Content) | `GET /generated-contents` (paginated `useInfiniteQuery`), `POST /generated-contents/:id/duplicate`, `POST /generated-contents/:id/regenerate`, `DELETE /generated-contents/:id` | Loading: `SkeletonContentCard` list. Empty: `EmptyState` "No generated content". Error: `ErrorState`. Mutation feedback: channel picker action sheet, non-optimistic mutation with toast and query invalidation. Pull-to-refresh. |
| `/jobs/:id` | `src/app/(app)/jobs/[id].tsx` | `GET /jobs/:id`, `POST /jobs/:id/retry`, `POST /jobs/:id/cancel` | Loading: `SkeletonRows` + detail layout skeleton. Error: `ErrorState`. Mutation feedback: action button loading states, confirm dialog for cancellation, toasts. Polling: 5s while non-terminal. RTL-aware text rendering for Urdu. |
| `/generated-contents/:id` | `src/app/(app)/generated/[id].tsx` | `GET /generated-contents/:id`, `POST /generated-contents/:id/duplicate`, `POST /generated-contents/:id/regenerate`, `DELETE /generated-contents/:id` | Loading: image/video + typography skeleton. Error: `ErrorState`. Mutation feedback: confirm dialog for delete, channel selector for duplicate/regenerate, toasts. Media unavailable fallback if Cloudinary media retention expired. |
| `/queue` | `src/app/(app)/queue.tsx` | `GET /queue/stats`, `GET /jobs` (filters), `GET /scheduler/upcoming`, `POST /jobs/:id/approve`, `POST /jobs/:id/reject`, `POST /jobs/:id/retry`, `POST /jobs/:id/cancel` | Loading: queue summary skeleton + job cards skeleton. Empty: `EmptyState` for waiting/review items. Error: `ErrorState`. Mutation feedback: approve/reject confirmation with reason sheet, button spinners, toasts. Polling: 10s for stats/jobs, 30s for upcoming. |
| `/publishing-history` | `src/app/(app)/(tabs)/publishing.tsx` | `GET /publishing-history` (paginated `useInfiniteQuery`), `POST /publishing-history/:id/retry`, `POST /publishing-history/republish` | Loading: `SkeletonCard` list. Empty: `EmptyState` "No publishing records found". Error: `ErrorState`. Filter sheet for platform/status/channel. Mutation feedback: channel picker for republish, retry button loader, toasts. |
| `/publishing-history/:id` | `src/app/(app)/publishing/[id].tsx` | `GET /publishing-history/:id`, `POST /publishing-history/:id/retry`, `POST /publishing-history/republish` | Loading: detail card skeletons. Error: `ErrorState`. Mutation feedback: retry/republish loaders, toasts. External link validator for `publishedUrl`. |
| `/notifications` | `src/app/(app)/(tabs)/alerts.tsx` | `GET /notifications` (paginated `useInfiniteQuery`), `GET /notifications/unread-count`, `POST /notifications/:id/read`, `POST /notifications/read-all`, `DELETE /notifications/:id` | Loading: `SkeletonList`. Empty: `EmptyState` "No alerts". Error: `ErrorState`. Mutation feedback: optimistic mark read, mark all read, delete with rollback on failure; toasts. Filter sheet for status/type/date. SSE realtime updates with automatic REST polling fallback. |
| `/notifications/:id` (Modal) | `src/app/(app)/notifications/[id].tsx` | `GET /notifications/:id`, `POST /notifications/:id/read`, `DELETE /notifications/:id` | Loading: modal detail skeleton. Error: `ErrorState`. Mutation feedback: read/delete action toasts. |
| `/channels` | `src/app/(app)/channels/index.tsx` | `GET /channels`, `DELETE /channels/:id`, `POST /channels/:id/duplicate` | Loading: `SkeletonCard` list. Empty: `EmptyState` with "Create Channel" button. Error: `ErrorState`. Mutation feedback: duplicate / delete confirm dialogs and toasts. |
| `/channels/new` | `src/app/(app)/channels/new.tsx` | `POST /channels`, `GET /content-profiles`, `GET /platform-connections` | Loading: picker skeletons while loading profiles/connections. Form validation: RHF + Zod with strict 5-field cron regex. Mutation feedback: submit button loader, success toast + navigation to list. |
| `/channels/:id` | `src/app/(app)/channels/[id].tsx` | `GET /channels/:id`, `PUT /channels/:id`, `DELETE /channels/:id`, `POST /channels/:id/duplicate`, `GET /content-profiles`, `GET /platform-connections` | Loading: form skeleton. Error: `ErrorState`. Mutation feedback: save loader, delete confirmation dialog, toasts. |
| `/content-profiles` | `src/app/(app)/content-profiles/index.tsx` | `GET /content-profiles`, `DELETE /content-profiles/:id` | Loading: `SkeletonCard` list. Empty: `EmptyState` with "Create Profile" button. Error: `ErrorState`. Mutation feedback: delete confirm dialog + toast. |
| `/content-profiles/new` | `src/app/(app)/content-profiles/new.tsx` | `POST /content-profiles`, `GET /content-types`, `GET /prompts`, `GET /prompts/:id/versions`, `GET /templates`, `GET /templates/:id`, `GET /assets?type=Background` | Loading: options loading skeletons. Form: full multi-section form with strict sub-object schemas (`promptVariables`, `brandingRules`, `watermarkRules`, `captionStrategy`, `hashtagStrategy`, `musicSelectionRules`, `backgroundSelectionRules`, `renderingConfiguration`, `validationRules`). Mutation feedback: submit loader, success toast. |
| `/content-profiles/:id` | `src/app/(app)/content-profiles/[id].tsx` | `GET /content-profiles/:id`, `PUT /content-profiles/:id`, `DELETE /content-profiles/:id`, `GET /content-profiles/:id/readiness`, `POST /content-profiles/:id/dry-run`, `GET /jobs/:id` | Loading: read-only detail skeleton / edit section skeleton. Readiness badge, dry-run button triggers job and polls `GET /jobs/:id` every 3s until terminal. Mutation feedback: save loader, delete confirm dialog, toasts. |
| `/prompts` | `src/app/(app)/prompts/index.tsx` | `GET /prompts`, `GET /prompts/output-contract` | Loading: `SkeletonCard` list. Empty: `EmptyState`. Error: `ErrorState`. Output-contract bottom sheet. |
| `/prompts/:id` | `src/app/(app)/prompts/[id].tsx` | `GET /prompts/:id`, `GET /prompts/:id/versions`, `POST /prompts/:id/versions/:versionNumber/rollback` | Loading: version history skeleton. Error: `ErrorState`. Mutation feedback: rollback confirm dialog, button loader, toast. |
| `/prompts/:id/new-version` | `src/app/(app)/prompts/[id]/new-version.tsx` | `POST /prompts/:id/versions` | Form validation: RHF + Zod (name, body with monospace editor, variables, notes). Mutation feedback: save button loader, toast + navigate back. |
| `/templates` | `src/app/(app)/templates/index.tsx` | `GET /templates` | Loading: `SkeletonCard` list with preview image skeletons. Empty: `EmptyState`. Error: `ErrorState`. |
| `/templates/:id` | `src/app/(app)/templates/[id].tsx` | `GET /templates/:id`, `GET /templates/:id/versions/:n/preview`, `POST /templates/:id/versions/:n/rollback` | Loading: detail + version preview skeleton. Error: `ErrorState`. Read-only collapsible monospace definition view. Mutation feedback: rollback confirm dialog, toast. |
| `/assets` | `src/app/(app)/assets/index.tsx` | `GET /assets?type=`, `DELETE /assets/:id` | Loading: `SkeletonCard` grid/list. Empty: `EmptyState` per asset type. Error: `ErrorState`. Mutation feedback: delete confirm dialog, toast. |
| `/assets/new` | `src/app/(app)/assets/new.tsx` | `POST /assets` (multipart `FormData`) | Picker integration: `expo-image-picker` (Background, Logo, Watermark, Icon), `expo-document-picker` (Music `audio/*`, Font `font/*`). Progress bar via `onUploadProgress`, 60s timeout, AbortController cancel. Cellular warning > 25MB, rejection > 100MB. Toast on completion. |
| `/assets/:id` | `src/app/(app)/assets/[id].tsx` | `GET /assets/:id`, `PUT /assets/:id`, `DELETE /assets/:id` | Loading: asset detail skeleton. Edit name, status, license status, startTime/endTime (music trim). Mutation feedback: save loader, delete confirm dialog, toasts. |
| `/content-types` | `src/app/(app)/content-types.tsx` | `GET /content-types`, `POST /content-types`, `PUT /content-types/:id`, `DELETE /content-types/:id` | Loading: `SkeletonList`. Empty: `EmptyState`. Error: `ErrorState`. CRUD modal sheet, submit loaders, delete confirm dialog, toasts. |
| `/workspaces` | `src/app/(app)/workspaces.tsx` | `GET /workspaces`, `POST /workspaces`, `PUT /workspaces/:id`, `DELETE /workspaces/:id` | Loading: `SkeletonList`. Empty: `EmptyState`. Error: `ErrorState`. Full CRUD with confirm dialogs and toasts. |
| `/platform-connections` | `src/app/(app)/connections.tsx` | `GET /platform-connections`, `GET /oauth/youtube/authorize`, `PUT /platform-connections/:id`, `DELETE /platform-connections/:id` | Loading: `SkeletonCard` list. Empty: `EmptyState`. Role check: Owner/Admin only for mutations. YouTube OAuth via `WebBrowser.openAuthSessionAsync`, refetch connections on return, toast feedback. Rename/status modal, delete confirm dialog. |
| Global Search | `src/app/(app)/search.tsx` (Modal) | `GET /search?q=` (debounced 300ms, min 2 chars) | Loading: skeleton search results. Empty: "No search matches found". Grouped SectionList (Channels, Prompts, Templates, Profiles, Jobs & Pipeline, Publications, Assets, Generated Content). Tap deep links to item detail screen. |
| `/settings` | `src/app/(app)/settings.tsx` | `GET /auth/session`, `POST /auth/logout` | Operator email, role, workspace ID, app version/build, API host, legal links (Privacy Policy, Terms of Service). Sign out with confirm dialog. |
| `/logs` | *Deliberately Omitted* | None (backend has no `/logs` endpoint; web import was broken) | N/A |
